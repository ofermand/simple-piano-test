# גרסת אייפון — סימפל פיאנו

הפרויקט כולל את כל זרימת ״כוכב קטן״: לימוד דו וסול, תרגול, נגינה עם
ליווי, תוצאות ופתיחת לה, פה, מי ורה. יש קריינות בעברית, קלידים וחמשה,
זיהוי צלילים ודיאזים, שתי מהירויות, השהיה והתחלה מחדש.

## הפעלה

צריך Mac עם Xcode 16 ומעלה, ואייפון עם iOS 16 ומעלה.

1. פותחים את `SimplePiano.xcodeproj` ב־Xcode.
2. בוחרים את יעד SimplePiano וב־Signing & Capabilities בוחרים Team של Apple.
3. משנים את Bundle Identifier למזהה ששייך למפתח.
4. מחברים את האייפון, בוחרים אותו כיעד ולוחצים Run.
5. מאשרים הרשאת מיקרופון, מניחים ליד הפסנתר ולוחצים ״התחלה״.

קריינות נשענת על קול עברי שמותקן באייפון. אם חסר קול, האפליקציה מציגה
הסבר וממשיכה עם הוראות כתובות. הליווי נוצר במכשיר ואין העלאת הקלטות.

## בדיקות והפצה

שבע בדיקות ליבה עברו בסביבת Linux. בנוסף, בניית ניסיון בשרת macOS של
GitHub הצליחה: בדיקות Swift, בניית סימולטור ובניית Release לא חתומה לאייפון.
[תוצאת הבנייה](https://github.com/ofermand/simple-piano-test/actions/runs/44161516993)
מתייחסת לקוד ב־commit `0fa5190`.

עדיין לא בוצעו הרצה בסימולטור, חתימה, התקנה או בדיקה במכשיר. הפרויקט
והקובץ לסימולטור אינם IPA להתקנה. ל־TestFlight נדרשים חשבון Apple Developer
וחתימה; לבדיקה מקומית ניתן להשתמש ב־Mac עם Xcode וחשבון Apple רגיל.

ביטול ההד הוא ניסיוני: כשעיבוד הקול זמין, תו נכון ויציב יכול לקטוע את
הקריינות. אם אינו זמין, התרגול מחכה לסיום ההנחיה. יש לבדוק קודם שתיקה
בזמן הקריינות, ואז נגינה בזמן הקריינות; אין הבטחה להפרדה אקוסטית מלאה.

ראו `README.md` לפקודות הבנייה, פירוט הבדיקות והמגבלות.
